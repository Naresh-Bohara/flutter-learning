# 🧠 Learning Philosophy

For every important concept, I try to understand:

```text
What is it?
     ↓
Why does it exist?
     ↓
How does it work?
     ↓
When should I use it?
     ↓
What problem does it solve?
     ↓
How is it used in real applications?
```

I don't want to simply memorize syntax or copy code from tutorials.

I want to **understand → implement → debug → improve → build**.
